# 实现纲要 API 参考

**用途：** 本文件是实现纲要技能的 API 速查手册。AI 在编写代码时遇到 API 用法疑问，应查阅本文件。

**API 入口：** `window.实现纲要`（数据文件 `.data.js` 中通过 `const api = 实现纲要;` 访问）

**数据文件结构：** `.data.js` 定义 `function 执行工作数据() { const api = 实现纲要; ... }`，HTML 自动加载并执行此函数。

**完整实现：** 所有 API 的源码和 JSDoc 注释在 `templates/engine-v3.js` 中。

---

## 阶段控制 API

### 设置阶段

```javascript
api.设置阶段(阶段.类型识别);     // 1 — 项目样貌
api.设置阶段(阶段.接口分化);     // 2 — 接口分化
api.设置阶段(阶段.实现约定);     // 3 — 实现约定
```

| 阶段 | 含义 | 主要操作 |
|------|------|----------|
| 类型识别（一阶段） | 识别核心类型与关系 | 创建类型/函数/变量，建立关系，责任映射，分组 |
| 接口分化（二阶段） | 补充成员函数、成员变量 | 添加成员函数/变量，补全约束 |
| 实现约定（三阶段） | 约束集中与测试规划 | 约束集中扫描，添加测试项 |

> **设置阶段() 必须在创建任何类型之前调用，且全局只能调用一次。** 第二次调用会抛出错误——这是有意设计，防止 AI 在文档中间随意切换阶段。

## 项目与跨项目 API

### 设置项目名称

```javascript
api.设置项目名称('订单系统');
```

设置当前项目名称，作为节点 ID 的**命名空间前缀**。设置后，所有 `api.添加节点()` / `api.添加类()` 等创建的节点 ID 自动加 `项目名.` 前缀。

- 引用**同项目**类型可用短名（解析节点 ID 时自动补全前缀）
- 引用**他项目**类型须用 `项目名.类型名` 全名
- **会重置阶段上下文**：每个项目命名空间拥有独立的阶段设定权。跨项目场景下，被加载的文件已设置阶段二，主文件调用本 API 后可重新设置阶段一

> 单项目实现纲要不需要调用本 API。

### 加载数据

```javascript
api.加载数据('../依赖项目/实现纲要-依赖项目.data.js');
```

加载其他项目的实现纲要数据文件（跨项目引用）。

| 参数 | 类型 | 说明 |
|------|------|------|
| 文件路径 | string | 相对于 HTML 文件所在目录的路径 |

- **必须在编写本项目数据之前调用**（区域 1），以便被引用的类型在引用时已存在于数据仓库中
- 被加载的 `.data.js` 内部通过全局 `window.实现纲要` 访问 API
- 内部优先使用同步 XHR 读取；若被 CORS 拦截（`file://` 协议下常见），自动回退到 `document.write` 注入 `<script src>`，**两种加载方式均可用**

## 创建 API（按类型分化）

### 类型代理

```javascript
// 类
const 认证服务 = api.添加类({ id: '认证服务', 名称: '认证服务', 置信度: '高' });

// 接口
const I令牌存储 = api.添加接口({ id: 'I令牌存储', 名称: 'I令牌存储', 置信度: '高' });

// 结构体
const 用户信息 = api.添加结构体({ id: '用户信息', 名称: '用户信息', 置信度: '高' });

// 枚举（必须提供枚举值）
const 副作用分类 = api.添加枚举({ id: '副作用分类', 名称: '副作用分类', 枚举值: ['纯函数', '外部数据源', '有副作用'], 置信度: '高' });
```

| 参数 | 类型 | 说明 |
|------|------|------|
| id | string | 节点唯一标识 |
| 名称 | string | 显示名称 |
| 置信度 | '高' / '中' / '低' | 从需求中提取的可信度（可选，默认'中'） |
| 枚举值 | string[] | 仅枚举类型需要 |

**返回值：** 类型代理，可调用 拥有/继承/实现/符合约定/符合/调用/依赖/设置关系/添加关系/添加成员函数/批量添加成员函数/添加变量/添加成员变量/批量添加成员变量/设置签名/附加约定/添加测试/添加约束/获取约束/用到的变量

### 函数代理

```javascript
// 自由函数
const 创建认证服务 = api.添加函数({
  id: '创建认证服务()',
  名称: '创建认证服务()',
  签名: '认证服务* (容器&)',
  置信度: '高'
});
```

| 参数 | 类型 | 说明 |
|------|------|------|
| id | string | 节点唯一标识 |
| 名称 | string | 显示名称 |
| 签名 | string | 函数签名（可选） |
| 置信度 | string | 置信度（可选） |

**返回值：** 函数代理，可调用 调用/依赖/符合/符合约定/设置关系/添加关系/用到的变量/附加约定/获取约束/添加测试/添加约束

### 添加自由函数

```javascript
const 登录 = api.添加自由函数({
  id: '登录',
  名称: '登录',
  签名: 'bool (const string&, const string&)',
  置信度: '中'
});
```

等价于 `api.添加节点({ ...配置, 类型: 'func' })`，命名更清晰。必须提供 `id` 或 `名称`。

与 `添加函数()` 完全等价，两者可互换使用。

### 变量代理

```javascript
// 自由变量
const 全局配置 = api.添加变量({
  id: '全局配置',
  名称: '全局配置',
  类型: 'Config',
  置信度: '高'

```

| 参数 | 类型 | 说明 |
|------|------|------|
| id | string | 节点唯一标识 |
| 名称 | string | 显示名称 |
| 类型 | string | 变量类型 |
| 置信度 | string | 置信度（可选） |

**返回值：** 变量代理（无特殊方法，只存储数据）

## 关系 API

### 代理.添加关系()（第一阶段通用接口）

```javascript
// 第一阶段：用通用接口建立关系
认证服务.添加关系(令牌管理器, '拥有');
令牌管理器.添加关系(I令牌存储, '继承');
```

| 参数 | 类型 | 说明 |
|------|------|------|
| 目标代理 | 代理 或 string | 目标代理对象或其 id |
| 关系类型 | string | 关系类型字符串（见下表） |

**支持的关系类型：**

| 关系类型 | 第二阶段映射 |
|----------|-------------|
| '拥有' | 代理.拥有(B) |
| '继承' | 代理.继承(B) |
| '实现' | 代理.实现(B) |
| '符合约定' | 代理.符合约定(B) |
| '符合' | 代理.符合(B) |
| '调用' | 代理.调用(B) |
| '依赖' | 代理.依赖(B) |
| 自定义名称 | 保持原样 |

> 第一阶段允许使用任意关系类型字符串。第二阶段引擎自动将 添加关系() 替换为对应的具体方法。

### 代理.设置关系(B, 关系类型)

`添加关系()` 的等价底层形式，参数顺序为目标 + 关系类型。

### 代理.拥有(B)

```javascript
认证服务.拥有(令牌管理器);
```

A 持有/包含 B（成员变量、成员函数或子类型）。

### 代理.继承(B)

```javascript
令牌管理器.继承(I令牌存储);
```

A 继承/实现 B（类实现接口、子类继承父类）。

### 代理.实现(B)

```javascript
用户仓库.实现(I用户存储);
```

A 显式实现接口 B。

### 代理.符合约定(B)

```javascript
认证服务.符合约定(IComparable);
```

A 遵守约定类型 B 的要求。B 必须是约定类型（标记为 是约定类型: true）。

### 代理.符合(B)

```javascript
消息队列.符合(认证服务);
```

A 满足 B 的设计时条件。前提：A 已通过 符合约定 符合某个约定类型 C，而 B 的条件正是基于 C。

### 代理.调用(B)

```javascript
验证令牌.调用(令牌管理器);
```

A 调用 B（函数调用函数、函数调用类型）。

### 代理.依赖(B)

```javascript
验证令牌.依赖(I令牌存储);
```

A 依赖 B 类型（应在 B 之后编写）。

### 添加约定边

```javascript
api.添加约定边({ 源id: '认证服务', 目标id: 'IComparable' });
api.添加约定边({ 普通节点id: '认证服务', 目标id: 'IComparable', 关系类型: '符合' });
```

创建一个"约定"类型的边。

| 参数 | 类型 | 说明 |
|------|------|------|
| 源id / 普通节点id | string | 源节点 id（两种写法等价） |
| 目标id | string | 目标节点 id |
| 关系类型 | string | 可选，默认为 '符合' |

> 通常不需要直接调用——用 `附加约定()` 可一次完成标记 + 建边 + 加标记。本 API 适用于只想建边、不做约定标记的场景。

### 附加约定

将普通类型/函数绑定到约定类型——**一次调用完成标记 + 边 + 约定标记**。

```javascript
// 顶层形式：附加约定(普通节点id, 约定类型id)
api.附加约定('认证服务', 'IComparable');

// 代理形式：一次调用完成，链式更自然
const 消息队列 = api.添加类({ id: '消息队列', 置信度: '中' });
消息队列.附加约定('IComparable');
```

一次调用等同完成三件事：

1. 标记目标节点为约定类型（圆形节点）
2. 创建 `源 → 约定` 的 **符合约定** 边
3. 给源节点加上约定标记（橙色阴影）

> **注意：** 附加约定() 会将约定类型节点从类型视图移至约定视图。约定类型节点在类过滤器中不可见，需勾选约定才能看到。

## 成员 API（类型代理）

### 添加成员函数

```javascript
认证服务.添加成员函数({
  名称: '登录',
  职责: '验证用户名密码并返回token',
  有签名: true,
  签名提示: 'Token (const string&, const string&)',
  对应需求条目: 'REQ-001'
});
```

**返回值：** 成员函数代理（可调用 调用/依赖/添加关系/用到的变量/添加测试/添加约束）

### 添加变量（成员变量）

```javascript
// 名称和类型都提供
认证服务.添加变量({ 名称: '令牌管理器', 类型: '令牌管理器' });

// 只有名称（类型待定）
认证服务.添加变量({ 名称: 'token' });

// 只有类型（名称待定，自动创建拥有边）
认证服务.添加变量({ 类型: 'I服务接口', id: 'I服务接口' });
```

| 参数 | 类型 | 说明 |
|------|------|------|
| 名称 | string | 字段名称（可选） |
| 类型 | string 或 代理 | 字段类型（可选） |
| id | string | 当类型为代理时，指定目标节点 id |

> 名称和类型至少提供一个。两者都提供时创建成员变量节点 + 拥有边。

### 批量添加成员函数

```javascript
认证服务.批量添加成员函数([
  { 名称: '登录', 职责: '验证凭据并返回 token' },
  { 名称: '登出', 职责: '使当前 token 失效' }
]);

// 也支持变参写法（不传数组，逐个传配置对象）
认证服务.批量添加成员函数({ 名称: '登录' }, { 名称: '登出' });
```

| 参数 | 类型 | 说明 |
|------|------|------|
| 函数配置数组 | Array | 每个元素的字段与 `添加成员函数()` 完全一致 |

> 内部逐个调用 `添加成员函数()`，因此每个成员函数的校验与自动建边行为完全相同。适合一次性补全某个类型的方法列表。

### 批量添加成员变量

```javascript
认证服务.批量添加成员变量([
  { 名称: '令牌管理器', 类型: '令牌管理器' },
  { 名称: 'token', 类型: 'string' }
]);

// 同样支持变参写法
认证服务.批量添加成员变量({ 名称: 'token' }, { 名称: '过期时间' });
```

| 参数 | 类型 | 说明 |
|------|------|------|
| 变量配置数组 | Array | 每个元素的字段与 `添加变量()` 完全一致 |

> 内部逐个调用 `添加变量()`，自动建拥有边与类型依赖边。

### 设置签名

```javascript
认证服务.设置签名('Token (const string&, const string&)');
```

为节点单独设置/覆盖签名文本，显示在节点名称下方。

| 参数 | 类型 | 说明 |
|------|------|------|
| 签名文本 | string | 返回值 + 参数签名 |

> 与 `添加成员函数({ 有签名: true, 签名提示: '...' })` 的区别：后者在**创建时**指定签名，本 API 用于**事后补充或修改**已有节点的签名。

### 获取约束

```javascript
const 约束列表 = 认证服务.获取约束();
```

返回该节点已添加的约束数组（无约束时返回空数组）。用于检查某个节点是否已声明约束、避免重复添加。

## 测试 API

### 添加测试（多对多）

一条测试项可以**依附 0 个、1 个或多个节点**。

```javascript
// 1) 依附调用者自身（最常用）
认证服务.添加测试({ 标题: '用户登录成功时返回 token' });

// 2) 一条测试覆盖多个节点
认证服务.添加测试({
  标题: '登录后各服务都能读到 token',
  覆盖: ['认证服务', '令牌管理器', '用户仓库']
});

// 3) 顶层调用：不传 覆盖 = 独立测试（不依附任何节点）
api.添加测试({ 标题: '系统端到端冒烟测试' });
```

| 参数 | 类型 | 说明 |
|------|------|------|
| 标题 | string | 测试标题（必填） |
| 覆盖 | string \| string[] | 覆盖的节点 id（单个或数组）；省略 = 不依附任何节点 |

**返回值：** 测试项 id（字符串，如 `'测试1'`）。

> - **代理形式**（`节点.添加测试()`）默认覆盖调用者自身；传了 `覆盖` 则用它替换
> - **顶层形式**（`api.添加测试()`）不传 `覆盖` 即为**独立测试**，会显示在右侧面板的「🧪 独立测试」区块
> - 类型代理、函数代理、成员函数代理、成员变量代理都可以调用
> - UI 呈现：节点详情列出「覆盖到本节点」的全部测试，跨节点的标 `🔗 N 个节点`；
>   测试规划视图的 `🧪N` 角标 = 该节点相关测试数（含被其他测试覆盖过来的）
> - 依附建议：挂在**直接被测的目标**上，不要挂在它间接调用的接口/类型上

api.设置责任映射('认证服务', 'REQ-001', '处理用户登录、注册、token管理');

## 代理能力总览

引擎中共用一个通用代理对象（类型/函数/变量代理方法集相同），成员函数与成员变量代理为独立对象：

| 代理类型 | 可调用的方法 |
|----------|-------------|
| **类型代理**（添加类/接口/结构体/枚举） | 拥有 · 继承 · 实现 · 符合约定 · 符合 · 调用 · 依赖 · 设置关系 · 添加关系 · 添加成员函数 · 批量添加成员函数 · 添加变量 · 添加成员变量 · 批量添加成员变量 · 设置签名 · 附加约定 · 添加测试 · 添加约束 · 获取约束 · 用到的变量 · `[]` 运算符 |
| **函数代理**（添加函数 / 添加自由函数） | 调用 · 依赖 · 符合 · 符合约定 · 设置关系 · 添加关系 · 用到的变量 · 附加约定 · 获取约束 · 添加测试 · 添加约束 |
| **成员函数代理**（类型.添加成员函数() 的返回值） | 调用 · 依赖 · 添加关系 · 用到的变量 · 添加测试 · 添加约束 |
| **成员变量代理**（类型.添加变量() 的返回值） | 添加关系 · 添加测试 · 添加约束 |
