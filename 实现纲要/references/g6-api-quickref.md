﻿# 实现纲要 API 参考

**用途：** 本文件是实现纲要技能的 API 速查手册。AI 在编写代码时遇到 API 用法疑问，应查阅本文件。

**API 入口：** `window.实现纲要`（数据文件 `.data.js` 中通过 `const api = 实现纲要;` 访问）

**数据文件结构：** `.data.js` 定义 `function 执行工作数据() { const api = 实现纲要; ... }`，HTML 自动加载并执行此函数。

**完整实现：** 所有 API 的源码和 JSDoc 注释在 `templates/engine-v3.js` 中。

---

## 阶段控制 API

### 设置阶段

`javascript
api.设置阶段(阶段.类型识别);     // 1 — 项目样貌
api.设置阶段(阶段.接口分化);     // 2 — 接口分化
api.设置阶段(阶段.实现约定);     // 3 — 实现约定
`

| 阶段 | 含义 | 主要操作 |
|------|------|----------|
| 类型识别（一阶段） | 识别核心类型与关系 | 创建类型/函数/变量，建立关系，责任映射，分组 |
| 接口分化（二阶段） | 补充成员函数、成员变量 | 添加成员函数/变量，补全约束 |
| 实现约定（三阶段） | 约束集中与测试规划 | 约束集中扫描，添加测试项 |

> **设置阶段() 必须在创建任何类型之前调用，且全局只能调用一次。** 第二次调用会抛出错误——这是有意设计，防止 AI 在文档中间随意切换阶段。

## 创建 API（按类型分化）

### 类型代理

`javascript
// 类
const 认证服务 = api.添加类({ id: '认证服务', 名称: '认证服务', 置信度: '高' });

// 接口
const I令牌存储 = api.添加接口({ id: 'I令牌存储', 名称: 'I令牌存储', 置信度: '高' });

// 结构体
const 用户信息 = api.添加结构体({ id: '用户信息', 名称: '用户信息', 置信度: '高' });

// 枚举（必须提供枚举值）
const 副作用分类 = api.添加枚举({ id: '副作用分类', 名称: '副作用分类', 枚举值: ['纯函数', '外部数据源', '有副作用'], 置信度: '高' });
`

| 参数 | 类型 | 说明 |
|------|------|------|
| id | string | 节点唯一标识 |
| 名称 | string | 显示名称 |
| 置信度 | '高' / '中' / '低' | 从需求中提取的可信度（可选，默认'中'） |
| 枚举值 | string[] | 仅枚举类型需要 |

**返回值：** 类型代理，可调用 拥有/继承/实现/符合约定/符合/调用/添加成员函数/添加变量/添加测试/添加约束/添加关系

### 函数代理

`javascript
// 自由函数
const 创建认证服务 = api.添加函数({
  id: '创建认证服务()',
  名称: '创建认证服务()',
  签名: '认证服务* (容器&)',
  置信度: '高'
});
`

| 参数 | 类型 | 说明 |
|------|------|------|
| id | string | 节点唯一标识 |
| 名称 | string | 显示名称 |
| 签名 | string | 函数签名（可选） |
| 置信度 | string | 置信度（可选） |

**返回值：** 函数代理，可调用 调用/依赖/符合/用到的变量/添加测试/添加约束/添加关系

### 变量代理

`javascript
// 自由变量
const 全局配置 = api.添加变量({
  id: '全局配置',
  名称: '全局配置',
  类型: 'Config',
  置信度: '高'
});
`

| 参数 | 类型 | 说明 |
|------|------|------|
| id | string | 节点唯一标识 |
| 名称 | string | 显示名称 |
| 类型 | string | 变量类型 |
| 置信度 | string | 置信度（可选） |

**返回值：** 变量代理（无特殊方法，只存储数据）

## 关系 API

### 代理.添加关系()（第一阶段通用接口）

`javascript
// 第一阶段：用通用接口建立关系
认证服务.添加关系(令牌管理器, '拥有');
令牌管理器.添加关系(I令牌存储, '继承');
`

| 参数 | 类型 | 说明 |
|------|------|------|
| 目标代理 | 代理 或 string | 目标代理对象或其 id |
| 关系类型 | string | 关系类型字符串（见下表） |

**支持的关系类型：**

| 关系类型 | 第二阶段映射 |
|----------|-------------|
| '拥有' | 代理.拥有(B) |
| '继承' | 代理.继承(B) |
| '实现' | 代理.实现(B) |
| '符合约定' | 代理.符合约定(B) |
| '符合' | 代理.符合(B) |
| '调用' | 代理.调用(B) |
| '依赖' | 代理.依赖(B) |
| 自定义名称 | 保持原样 |

> 第一阶段允许使用任意关系类型字符串。第二阶段引擎自动将 添加关系() 替换为对应的具体方法。

### 代理.拥有(B)

`javascript
认证服务.拥有(令牌管理器);
`

A 持有/包含 B（成员变量、成员函数或子类型）。

### 代理.继承(B)

`javascript
令牌管理器.继承(I令牌存储);
`

A 继承/实现 B（类实现接口、子类继承父类）。

### 代理.实现(B)

`javascript
用户仓库.实现(I用户存储);
`

A 显式实现接口 B。

### 代理.符合约定(B)

`javascript
认证服务.符合约定(IComparable);
`

A 遵守约定类型 B 的要求。B 必须是约定类型（标记为 是约定类型: true）。

### 代理.符合(B)

`javascript
消息队列.符合(认证服务);
`

A 满足 B 的设计时条件。前提：A 已通过 符合约定 符合某个约定类型 C，而 B 的条件正是基于 C。

### 代理.调用(B)

`javascript
验证令牌.调用(令牌管理器);
`

A 调用 B（函数调用函数、函数调用类型）。

### 代理.依赖(B)

`javascript
验证令牌.依赖(I令牌存储);
`

A 依赖 B 类型（应在 B 之后编写）。

## 成员 API（类型代理）

### 添加成员函数

`javascript
认证服务.添加成员函数({
  名称: '登录',
  职责: '验证用户名密码并返回token',
  有签名: true,
  签名提示: 'Token (const string&, const string&)',
  对应需求条目: 'REQ-001'
});
`

**返回值：** 成员函数代理（可调用 调用/依赖/添加测试/添加约束）

### 添加变量（成员变量）

`javascript
// 名称和类型都提供
认证服务.添加变量({ 名称: '令牌管理器', 类型: '令牌管理器' });

// 只有名称（类型待定）
认证服务.添加变量({ 名称: 'token' });

// 只有类型（名称待定，自动创建拥有边）
认证服务.添加变量({ 类型: 'I服务接口', id: 'I服务接口' });
`

| 参数 | 类型 | 说明 |
|------|------|------|
| 名称 | string | 字段名称（可选） |
| 类型 | string 或 代理 | 字段类型（可选） |
| id | string | 当类型为代理时，指定目标节点 id |

> 名称和类型至少提供一个。两者都提供时创建成员变量节点 + 拥有边。

## 约束 API

### 添加约束

`javascript
认证服务.添加约束({
  条件: 'config 为空',
  触发效果: '使用默认配置',
  来源步骤: 2
});
`

> 类型代理和函数代理都可以调用 添加约束()。

## 测试 API

### 添加测试

`javascript
认证服务.添加测试({ 标题: '用户登录成功时返回 token' });
创建认证服务.添加测试({ 标题: '默认配置下创建成功' });
`

> 测试项存储在代理的 _测试项 属性数组中，不创建独立节点。类型代理和函数代理都可以调用 添加测试()。

## 工具 API

### 设置责任映射

`javascript
api.设置责任映射('认证服务', 'REQ-001', '处理用户登录、注册、token管理');
`

### 设置分组

`javascript
api.设置分组('核心服务', ['认证服务', '令牌管理器', '用户仓库']);
`

### 获取子代理

`javascript
// 通过名称访问类型代理的子项
const 令牌管理器代理 = 认证服务['令牌管理器'];
`

> 仅类型代理支持 [] 运算符。

### 导出数据

`javascript
const 数据 = api.导出全景图();
`
